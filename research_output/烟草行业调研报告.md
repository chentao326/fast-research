## 一、一句话总结

中国烟草是全球最大、利润最高、也最特殊的垄断行业——年利税超万亿、贡献全国财政收入的 6-8%，但正面临控烟全球化、新型烟草冲击、以及专卖制度长期存续性的三重拷问。

---

## 二、行业概览

### 2.1 定义与范围

烟草行业涵盖了从**烟叶种植→烟叶收购→卷烟生产→流通批发→零售终端**的全产业链。在中国，这一切由**中国烟草总公司（企业）+ 国家烟草专卖局（行政）**"一套机构两块牌子"统一管控，实行严格的专卖垄断制度。

### 2.2 市场规模

| 指标 | 数据 | 备注 |
|------|------|------|
| 年卷烟产量 | ~2.3-2.4 万亿支 | 全球第一，占 ~30% |
| 年卷烟销量 | ~2.5 万亿支 | 含少量进口 |
| 年利税总额 | ~1.2-1.4 万亿元 | 含税收+上缴利润 |
| 占全国财政收入 | ~6-8% | 部分省份占比更高 |
| 吸烟人口 | ~3 亿 | 占成年人口 ~25% |
| 行业从业人口 | ~2000 万+ | 含烟农+产业工人+零售 |

> **对比参照**：中国烟草年利税 ≈ 中国军费开支的 80%，或相当于 20+ 个茅台集团的净利润。

### 2.3 产业链结构

```
┌─────────────────────────────────────────────────┐
│               国家烟草专卖局（行政管理）            │
│               中国烟草总公司（企业经营）            │
│                 "一套机构，两块牌子"               │
└──────────────┬──────────────────────────────────┘
               │
   ┌───────────┼───────────┐
   ▼           ▼           ▼
┌──────┐  ┌──────┐   ┌──────────┐
│烟叶种植│→│复烤加工│→ │ 卷烟生产  │
│(农户) │  │(地方烟│   │(各省中烟) │
│       │  │ 草公司)│   │          │
└──────┘  └──────┘   └────┬─────┘
                          │
                          ▼
                    ┌──────────┐
                    │ 流通批发  │
                    │(地市级烟草│
                    │  公司)   │
                    └────┬─────┘
                          │
                          ▼
                    ┌──────────┐
                    │ 零售终端  │
                    │(持证零售户)│
                    │ ~500万户  │
                    └──────────┘
```

**各环节说明**：
- **烟叶种植**：云南、贵州、四川、湖南、河南等为主产区，由烟草公司统一收购，烟农无自主销售权
- **卷烟生产**：18 家省级中烟工业公司（如云南中烟、上海烟草、湖南中烟等），计划生产，无权自定产量
- **流通批发**：地市级烟草公司（商业企业）统一从工厂采购、统一批发给零售户
- **零售终端**：需持有《烟草专卖零售许可证》，从指定烟草公司进货，不得跨区串货

### 2.4 关键特点

**"计划经济堡垒"**：烟草是中国仅剩的几个实行全链条计划管理的行业之一——种植有指标、生产有计划、价格有管控、渠道有垄断。这不是市场竞争的结果，而是《烟草专卖法》的法律安排。

## 三、竞争格局

### 3.1 主要品牌与定位

| 品牌 | 所属中烟 | 年销量（估算） | 定位 |
|------|---------|--------------|------|
| 中华 | 上海烟草 | ~150 万箱 | 高端标杆，政务商务首选 |
| 利群 | 浙江中烟 | ~300 万箱 | 中高端，全国销量第一 |
| 芙蓉王 | 湖南中烟 | ~200 万箱 | 中高端，商务经典 |
| 黄鹤楼 | 湖北中烟 | ~200 万箱 | 中高端，文化营销 |
| 玉溪 | 云南中烟 | ~150 万箱 | 中高端，"清香之宗" |
| 云烟 | 云南中烟 | ~300 万箱 | 中端，全国性大单品 |
| 红塔山 | 云南中烟 | ~200 万箱 | 中低端，国民经典 |
| 南京 | 江苏中烟 | ~150 万箱 | 细支烟领先 |

### 3.2 竞争不是 "企业 vs 企业"，而是 "省份 vs 省份"

与一般行业不同，烟草的竞争不是市场化的企业间竞争，而是：
- **各省中烟公司之间的非市场化博弈**——谁能拿到更多生产计划指标，谁就赚钱
- **地方保护主义严重**——每个省都会优先卖本省中烟的烟
- **品牌是"准公共品"**——不能随意定价、不能打广告、不能在互联网销售

### 3.3 核心壁垒

| 壁垒类型 | 具体表现 | 可攻破性 |
|----------|---------|---------|
| **法律壁垒** | 《烟草专卖法》赋予的法定垄断 | ⭐ 除非修法，否则不可突破 |
| **渠道壁垒** | 500 万零售户的专卖网络 | ⭐⭐⭐ 新型烟草有绕过可能 |
| **品牌壁垒** | "中华"几十年积累的品牌势能 | ⭐⭐⭐ 高端市场仍需时间 |
| **产能壁垒** | 生产计划指标的分配权 | ⭐⭐ 省际博弈 |
| **税收壁垒** | 万亿利税让任何改革都投鼠忌器 | ⭐⭐⭐⭐⭐ 这才是终极护城河 |

## 四、关键洞察

### 4.1 烟草专卖制度的本质——"财政抽水机"

烟草专卖制度的核心不是保护人民健康（恰恰相反），而是**高效地从 3 亿烟民身上抽取财政收入**。

逻辑链：
- 生产端垄断 → 成本可控
- 批发端垄断 → 利润截留
- 零售端管控 → 防止价格战侵蚀利润
- 税收+上缴利润 → 1.2-1.4 万亿入国库

> 一条售价 1000 元的中华烟，税收和利润约 700 元归国家，200 元归零售户，真正的生产成本不足 100 元。

### 4.2 新型烟草的冲击与应对

**电子烟**：
- 2019 年前野蛮生长（悦刻等品牌爆发）
- 2021 年政策收紧——电子烟纳入专卖监管，线上禁售，口味限制
- 结果：行业大洗牌，非国资背景品牌基本出局
- 2023 年后，"国标电子烟"由中烟体系主导

**HNB（加热不燃烧）**：
- IQOS（菲利普莫里斯国际）全球火爆，但被挡在中国市场之外
- 云南中烟、四川中烟等已推出自主 HNB 产品（如 MC、功夫等）
- 政策态度：既不开放国外品牌，也不急于推广——怕冲击传统卷烟基本盘

**核心矛盾**：新型烟草代表未来方向，但每转化一个传统烟民就是在挖万亿利税的墙角。所以政策是"让它在可控范围内发展"。

### 4.3 控烟 vs 财政的两难

| 维度 | 控烟派 | 财政派 |
|------|--------|--------|
| 逻辑 | 吸烟 = 公共卫生灾难 | 烟草利税 = 国家财政支柱 |
| 每年死亡 | ~100 万（吸烟相关疾病） | — |
| 每年贡献 | — | 1.2-1.4 万亿 |
| 社保压力 | 医疗支出数千亿 | 但利税 > 医疗支出 |
| 国际压力 | WHO《烟草控制框架公约》 | "发展中国家，逐步推进" |

**残酷的现实**：中国签署了 WHO 控烟公约，但执行力度有限。因为—每年 1.2 万亿的利税，没有任何一个财政部官员敢说"我们可以不要"。

### 4.4 未来 10 年的可能变化

**大概率事件**（80%+）：
- 专卖制度继续存在，但控烟力度渐进加强
- 新型烟草市场由中烟体系主导，国外品牌继续被挡
- 卷烟产销量缓慢下降（年降 1-2%），但利税不降（结构升级：低端→中高端）

**中概率事件**（30-50%）：
- 新型烟草单独成立全国性公司（类似铁塔公司的模式）
- 部分省份中烟整合（减少内部竞争损耗）

**小概率事件**（<10%）：
- 专卖制度松动，允许社会资本进入某环节
- 中国加入 CPTPP 等贸易协定倒逼烟草市场开放

### 4.5 市场化改革假想——如果明天取消专卖

**谁赢**：
- 菲利普莫里斯、英美烟草等国际巨头（渠道打开）
- 新型烟草创业公司（不再被政策卡死）
- 消费者（价格下降、选择增多）

**谁输**：
- 中国烟草总公司（垄断利润归零）
- 各省级中烟公司（直面竞争，一半会死）
- 地方政府（尤其是云南等烟叶大省——烟草占地方财政收入可达 30%+）
- 国家财政（短期少 1 万亿，找什么填？）
- 500 万零售户（失去稳定货源和利润保障）

**因此短期内不可能取消。但长期来看，当吸烟率降到足够低、利税贡献不再不可替代时，改革窗口才会打开。**

## 五、调研局限

| 局限 | 原因 | 建议获取方式 |
|------|------|-------------|
| 各品牌精确销量和份额 | 中烟不公开发布分品牌数据 | 查阅烟草行业年鉴或付费数据库 |
| 新型烟草（电子烟/HNB）最新政策 | 政策变化频繁，离线知识可能滞后 | 搜索 2025-2026 年国家烟草专卖局公告 |
| 各省烟草对地方财政的实际贡献 | 各省数据不透明 | 查阅各省财政决算报告 |
| 国际比较（日本/韩国/欧美烟草改革路径） | 未做深入跨国比较 | 搜索 WHO 全球烟草报告、各国烟草改革案例 |
| 烟民消费行为变化趋势 | 需要一手调研数据 | 烟草行业消费者调研报告（尼尔森/凯度） |
