# 快速调研法 —— Prompt 模板库

> 以下模板可直接复制使用，替换 `{占位符}` 即可。

---

## 模板 1：调研启动指令

直接发给 AI 启动一次完整调研：

```
请使用快速调研法帮我调研【{调研对象}】。

模式：【快速/标准/深度】
调研目的：【面试准备/工作报告/个人兴趣/其他】

特别关注：【如有，填写你特别想了解的方向，可留空】

请按照五步流程执行：
1. 先列出问题清单，和我确认
2. 然后搜索二手信息建立框架
3. 再针对具体问题深度搜索
4. 整理成结构化报告
5. 最后回到最初的问题，验证是否回答完整
```

---

## 模板 2：步骤 2——二手信息框架搜索

AI 执行步骤 2 时的内部搜索 prompt：

```
请帮我搜索关于【{调研对象}】的基础信息，我需要建立框架性认知。
请覆盖以下维度：
1. 这个领域/行业是什么？一句话定义。
2. 市场规模多大？主要参与者是谁？（列 5-10 个）
3. 产业链是什么样的？（上下游关系）
4. 有哪些核心概念/术语我需要知道？
5. 最近半年发生了什么重要事件/趋势？

注意：不需要深度分析，只需要帮我建立一个"地图"。
```

---

## 模板 3：步骤 3——深度搜索追问

针对单个问题的深度搜索模板：

```
关于【{具体问题}】，请帮我深入调研：
1. 直接回答：这个问题的最核心答案是什么？
2. 支持证据：有什么数据或案例可以支撑？
3. 不同观点：这个问题上有没有争议？不同立场的人怎么看？
4. 再追问一层：为什么会这样？背后的原因是什么？
5. 趋势判断：未来会怎么变化？
```

---

## 模板 4：狠狠逼问 AI 的关键 Prompt

当 AI 回答太宽泛/太水时，用这几个 prompt 逼它给干货：

```
你说的太含糊了。把其中最重要的两点给我揪出来，用最精炼的语言。
```

```
不要说那些套话。如果只让你说一个最关键的数字和一个最反直觉的发现，是什么？
```

```
你刚才说的这些，有哪些是你确定有数据支撑的？哪些是你的推测？请把确定的和推测的分开。
```

```
换个角度重新回答。假设你是一个【竞品/投资人/消费者】，你会怎么看这个问题？
```

## 模板 5：步骤 4——报告生成 Prompt

调研完毕后生成完整报告的 prompt：

```
基于我们刚才所有的调研对话，请生成一份完整的调研报告，要求：
1. 一句话总结（放最前面）
2. 行业概览（定义/规模/产业链/发展历程）
3. 竞争格局（主要玩家/定位/策略）
4. 关键洞察（核心竞争力/趋势/风险/争议）
5. 调研局限（诚实标注哪些通过快速调研无法获得）
6. 进一步学习建议（推荐书单/内容/专家类型）
7. 附上问题回答对照表（我们最初的问题都回答了吗？）

格式要求：Markdown，层次分明，关键结论加粗。
```

## 模板 6：深度模式专属——寻找争议性观点

```
关于【{话题}】，请帮我找到至少 3 种不同的观点或立场：
1. 主流观点是什么？
2. 反对者怎么说？
3. 有没有人持完全不同的框架来看这个问题？
4. 这些分歧的根源是什么？（数据不同？假设不同？利益不同？）
```

---

## 模板 7：快速模式精简版

时间紧急时的精简调研流程：

```
请用 15 分钟快速帮我调研【{对象}】。只需要：
1. 列 3 个最核心的问题
2. 2 轮搜索建立框架
3. 深挖最核心的 1 个问题
4. 输出精简报告（只含：一句话总结、关键数据、核心洞察、局限）
5. 对照原始问题检查是否回答
```

---

## 模板 8：专家调研准备（辅助功能）

准备找人聊之前的调研辅助：

```
在找【{领域}】专家聊之前，帮我准备：
1. 我应该提前了解的 5 个基础概念
2. 最有价值的 5 个问题（问题要好到让对方觉得"你做过功课"）
3. 这个领域当前最热门的 3 个争议话题（适合聊天切入）
4. 我应该避免问的 3 个问题（太基础/太冒犯/太宽泛）
```

## 模板 9：学术调研书单生成

```
关于【{学科领域}】，帮我找入门书单：
1. 先推荐 1 本公认最好的启蒙书
2. 找出豆瓣上这本书所属的书单
3. 从书单中再推荐 3-5 本高质量入门书
4. 如果有条件，找到国内 Top 院校该专业考研参考书目
```
