# 快速调研法 Skill（AI 可执行版）

基于 B站 UP主「老蒋巨靠谱」的快速调研法方法论，封装为 AI 代理可直接执行的工作流。

---

## 使用方式

### 方式一：直接对话触发

在 Codex 中输入以下任意触发词：

```
调研一下新能源汽车行业
帮我快速了解香水行业
分析一下 AI Agent 赛道
我想知道集换式卡牌市场是怎么回事
/research 新能源汽车
```

AI 会自动加载此 skill，按五步法执行。

### 方式二：手动指定模式

```
调研新能源汽车行业，用快速模式
调研香水市场，用深度模式
```

### 方式三：复制 Prompt 模板

打开 `prompts.md`，复制对应模板，填入调研对象即可使用。

---

## 文件说明

| 文件 | 用途 |
|------|------|
| `SKILL.md` | Skill 定义文件，AI 读取后按工作流执行 |
| `prompts.md` | 9 个可复用的 Prompt 模板（调研启动/深度搜索/逼问AI/报告生成等） |
| `README.md` | 本文件 |

---

## 三种模式

| 模式 | 耗时 | 产出 | 适用 |
|------|------|------|------|
| ⚡ 快速 | ~30 分钟 | 精简报告（3 核心问题） | 面试准备、临时了解 |
| 📋 标准 | ~2 小时 | 完整报告（5-8 问题） | 工作汇报、新业务 |
| 🔬 深度 | 半天 | 完整报告 + 争议分析 + 书单 | 投资决策、重大项目 |

---

## 核心原则

1. **问题先行**——先列问题，再搜索
2. **以搜养收**——搜索中迭代优化问题
3. **AI 做 dirty work**——搜索、整理、格式化
4. **人做 high-level thinking**——判断、洞察、取舍
5. **标注局限**——诚实标注无法获得的信息
